## Menjalankan Secara Lokal

```bash
# 1. Configure CLI (sekali saja)
exercism configure --token=<token-kamu>

# 2. Download exercise
exercism download --exercise=<nama-exercise> --track=cpp

# 3. Kerjakan sampai test lulus, lalu submit
exercism submit <path-file-implementasi>
```
